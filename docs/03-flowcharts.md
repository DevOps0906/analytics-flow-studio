# 03. 플로차트 (Flowcharts)

> 기준 흐름: **파일 업로드 → 데이터분석처리단계(7단계) → 보고서 작성**

## 1. 전체 사용자 흐름

```mermaid
flowchart TD
  A(["시작: 로그인"]) --> B["대시보드<br/>(최근 프로젝트·이어서 할 일)"]
  B --> C{"새로 시작?"}
  C -- "예" --> D["업로드<br/>CSV·엑셀 끌어다 놓기"]
  C -- "아니오" --> P["프로젝트 목록에서 열기"]
  D --> E{"파일 검사 통과?"}
  E -- "아니오" --> E1["형식·크기·내용 오류 안내<br/>다시 올리기"] --> D
  E -- "예" --> F["데이터분석하기 버튼"]
  F --> G["데이터분석단계<br/>7단계 처리 시작"]
  G --> H["1~2단계: 목표 확인 + 수집·프로파일링"]
  H --> I["3단계: 정리 제안 확인"]
  I --> J["4~5단계: 탐색·분석 (자동)"]
  J --> K["6단계: 대시보드 + 보고서 초안 생성"]
  K --> L{"결과 마음에 드는가?"}
  L -- "수정 필요" --> M["말로 수정 요청<br/>(차트 유형·기간·강조)"] --> K
  L -- "좋음" --> N["보고서 내보내기<br/>PDF · Word · 공유 링크"]
  N --> O{"자동화 설정?"}
  O -- "예" --> Q["7단계: 파이프라인 저장·예약"]
  O -- "아니오" --> R(["완료: 프로젝트 보관"])
  Q --> R
  P --> K
```

## 2. 7단계 데이터분석처리 — 상태 흐름

```mermaid
stateDiagram-v2
  [*] --> Step1
  state "1 문제 정의·목표" as Step1
  state "2 데이터 수집" as Step2
  state "3 전처리·정제" as Step3
  state "4 탐색적 분석(EDA)" as Step4
  state "5 모델링·심층 분석" as Step5
  state "6 해석·시각화·보고서" as Step6
  state "7 자동화·파이프라인" as Step7

  Step1 --> Step1: 목표 수정
  Step1 --> Step2: 목표 확인(필수)
  Step2 --> Step3: 프로파일 완료
  Step2 --> Failed: 파싱 실패
  Step3 --> Step3: 제안 적용/건너뛰기
  Step3 --> Step4: 승인 완료(필수)
  Step4 --> Step5: 그래프 후보 확정
  Step5 --> Step6: 분석 결과 저장
  Step5 --> Failed: 연산 오류
  Step6 --> Step6: 말로 수정
  Step6 --> Step7: 완료 후 선택
  Step6 --> Done: 자동화 안 함
  Step7 --> Done: 저장
  Failed --> Step2: 파일 교체 후 재시도
  Failed --> Step5: 이 단계부터 재시도
  Done --> [*]
```

단계 상태값: `pending → running → waiting_user → done / failed` (화면의 진행바·애니메이션이 이 값을 그대로 표시)

## 3. 3단계 전처리·정제 — 제안 승인 흐름

```mermaid
flowchart TD
  A["프로파일 요약 생성"] --> B["Claude: 정리 제안 계획(JSON)"]
  B --> C["서버 검증 (스키마 + 허용 연산)"]
  C --> D["제안 4종 미리보기 계산<br/>날짜 통일 · 상품명 정리 · 결측 처리 · 이상치"]
  D --> E["화면: 제안 카드 (접기/펼치기, 변경 전·후)"]
  E --> F{"제안별 선택"}
  F -- "적용" --> G["정제 버전에 반영"]
  F -- "방법 선택(A/B)" --> G
  F -- "건너뛰기" --> H["변경 없음"]
  F -- "이상치: 건별 검토" --> I["유지 / 제외 / 직접 수정"] --> G
  G --> J["change_log 기록"]
  H --> K
  J --> K{"모든 제안 처리됨?"}
  K -- "아니오" --> E
  K -- "예" --> L["적용 후 요약 표시<br/>(결측 312→72 등)"]
  L --> M["새 데이터 버전 저장 → 4단계로"]
```

## 4. 6단계 보고서 작성 흐름

```mermaid
flowchart LR
  A["분석 결과<br/>(5단계)"] --> B["그래프 선택 규칙 적용<br/>컬럼 유형·항목 수 기준"]
  B --> C["대시보드 위젯 spec 생성"]
  A --> D["Claude: 인사이트 문장<br/>+ 근거 지표 연결"]
  C --> E["보고서 섹션 조립"]
  D --> E
  F["1단계 목표(KPI)"] --> E
  G["3단계 정리 이력"] --> E
  E --> H{"검수 규칙 통과?"}
  H -- "숫자 불일치/근거 없음" --> D
  H -- "통과" --> I["A4 미리보기"]
  I --> J["PDF (WeasyPrint)"]
  I --> K["Word (python-docx)"]
  I --> L["공유 링크 (읽기 전용)"]
```

검수 규칙 (자동)
1. 문장에 쓰인 숫자는 원본 계산 결과와 일치해야 함(불일치 시 재작성)
2. 모든 인사이트는 근거 위젯 1개 이상과 연결
3. 정리 이력이 있으면 부록에 반드시 포함
4. 샘플·가정 값은 "예시"로 표시

## 5. 그래프 선택 의사결정 흐름

```mermaid
flowchart TD
  S(["컬럼 조합 입력"]) --> A{"행 수 5개 이하?"}
  A -- "예" --> T["표 또는 KPI 카드"]
  A -- "아니오" --> B{"날짜 컬럼 있음?"}
  B -- "예" --> C{"숫자 컬럼 수"}
  C -- "1" --> L1["선 그래프 (대안: 영역)"]
  C -- "2~4, 같은 단위" --> L2["다중 선 (대안: 누적 영역)"]
  C -- "2, 단위 다름" --> L3["콤보 이중 축"]
  C -- "5 이상" --> L4["작은 다중 그래프"]
  B -- "아니오" --> D{"범주 컬럼 수"}
  D -- "0 (숫자만)" --> E{"숫자 컬럼 수"}
  E -- "1" --> H1["히스토그램 (대안: 상자 그림)"]
  E -- "2" --> H2["산점도"]
  E -- "3" --> H3["버블"]
  D -- "1" --> F{"항목 수"}
  F -- "7 이하" --> B1["세로 막대 (대안: 도넛)"]
  F -- "8~20" --> B2["가로 막대 정렬"]
  F -- "21 이상" --> B3["상위 10 + 기타"]
  D -- "2" --> G{"두 범주 항목 합계"}
  G -- "20 이하" --> G1["묶음/누적 막대"]
  G -- "20 초과" --> G2["히트맵"]
```

추가 규칙: 목표값이 있으면 불릿, 음수가 있으면 도넛 제외, 단위가 섞이면 이중 축 또는 분리, 결측 구간은 선을 끊고 점선 표기.

## 6. 질문 창(자연어) 처리 흐름

```mermaid
flowchart TD
  Q["사용자 질문"] --> A["의도 분류<br/>조회 / 비교 / 원인 설명 / 수정 요청"]
  A --> B["Claude: 분석 계획 JSON"]
  B --> C["검증 (스키마 + 허용 연산)"]
  C -- "불가" --> D["할 수 없는 이유 + 가능한 대안 제시"]
  C -- "가능" --> E["엔진 실행"]
  E --> F["답변 카드 (문장 + 표/차트 + 근거)"]
  F --> G{"사용자 선택"}
  G -- "대시보드에 고정" --> H["위젯 추가"]
  G -- "닫기" --> I["기록만 남김"]
  A -- "수정 요청" --> J["위젯 spec 변경안 생성"] --> K["적용 / 되돌리기"]
```

## 7. 자동화(7단계) 흐름 — v2

```mermaid
flowchart LR
  A["파이프라인 저장<br/>(목표·정리 규칙·그래프 설정)"] --> B["스케줄 / 새 파일 도착"]
  B --> C["n8n 트리거"]
  C --> D["웹훅: 분석 서비스 재실행"]

  E -- "예" --> F["저장된 규칙으로 자동 실행"]
  E -- "아니오" --> G["사용자에게 확인 요청<br/>(알림)"]
  F --> H["새 보고서 버전 생성"]
  H --> I["이메일/메신저 알림 + 대시보드 갱신"]
```
